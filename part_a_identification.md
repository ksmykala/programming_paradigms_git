# Part A – Identification

## Snippet 1

Concept: Property (@property)

Type: OOP

Explanation:
The @property decorator provides controlled access to an object's attribute.
It supports encapsulation and can be combined with validation logic.

---

## Snippet 2

Concept: Composition

Type: OOP

Explanation:
The Library class contains Playlist objects through its _playlists collection.
This represents a "has-a" relationship between Library and Playlist.

---

## Snippet 3

Concept: Strategy Pattern

Type: Pattern

Explanation:
The sorting behavior is delegated to a separate strategy object.
Different sorting algorithms can be used without changing the class itself.

---

## Snippet 4

Concept: Observer Pattern

Type: Pattern

Explanation:
Subscribers are notified whenever an event is published.
The publisher does not need to know who receives the notifications.
