This project's goal is to show how the same code can be written using different paradigms
we used imperative, procedural and functional. Each one of them is able to do that of course, with various levels of complexity.

Our project is also supposed to show expenses, calculate the total sum of all expenses, average expenses, count of all expenses,
most expensive transaction, least expensive transaction, all expenses above average, the d part of the project also formats the data.

The program can be run using following commands:

- imperative - python part_b_imperative.py
- procedural - python part_c_procedural.py
- functional - python part_d_functional.py

After analyzing each paradigm i have created a list of paradigms used in this project, ranked from easiest for me to hardest.

- Imperative - It was the easiest for me, since working on pure variables, doesn't need require skills in python, which for a beginner like myself
are a big plus.
- Procedural - This would be considered a more difficult paradigm for me but not by much, requires a bit more knowledge of python than imperative,
but it allowed me to improve in my skills as a python programmer.
- Functional - Without a doubt the hardest paradigm for me, mainly since I never tried it before the programming paradigms classes. I was forced to
contact internet, without much understanding of the code and having to check it again and again for more information.

If I had the option to do the whole project again I would certainly try to do much more of the d part of the project completely on my own, without contacting external
forums for help.
